# Pixel-level band correlations, per redshift bin

Computed on the **test** split, over every pixel of every galaxy in each redshift bin.

## Read this first

A raw Pearson correlation between any two bands is **~0.99 everywhere**, because every band is bright in the galaxy centre and faint at the edge. That number measures *"galaxies have centres"*, not spectral information. It is reported for completeness, but the two measures below are the ones that answer the question.

- **partial** — correlation between two bands with the other three held fixed. The unique, non-redundant link.
- **beta** — standardised regression coefficient: change in the target band per 1σ of the source band, other bands fixed. For target y these are exactly B1's standardised weights.

Three pixel regions are reported separately, because the galaxy and the sky behave differently: `all`, `aperture` (r=15 px, galaxy-dominated) and `outskirts` (sky/noise-dominated).
